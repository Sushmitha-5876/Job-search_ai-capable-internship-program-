# Job-search_ai-capable-internship-program-
Team - Shantanu kumar , Keerthana D , CS Rohith, Sushmitha M Chavan
AI Job Search Agent
A tool that automates the tedious part of job hunting — instead of manually scrolling through hundreds of listings, this agent pulls live job postings, compares them against a resume, and returns a ranked shortlist of the best-fit roles with reasoning for each match.
Built as a Colab notebook, it fetches real-time listings from RemoteOK, extracts resume content from a PDF, and uses Claude to score each job against the resume — highlighting not just how well it fits, but what skills are missing for roles that don't. The goal is to cut down the time spent sifting through irrelevant postings and help focus applications on jobs that are actually a good match.
